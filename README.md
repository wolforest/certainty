# 确定性 & [猜测](./guess.md) & [问题](./question.md)
AI时代，普通人并不适合乘风破浪。<br />
在不确定的时代，依赖确定性、通过学习构筑竞争优势，是普通人的生存之道。<br />
这一点对于软件工程师尤为重要，这个项目尝试收集AI时代的确定性及大概率的猜测。<br />
希望能同广大软件工程师一起成长、一起面对未来的挑战。

## AI & Software
* AI时代，软件依然是软件人安身立命的根本。
  * 不在于软件数量，而在于软件的成功，在于软件的影响力
  * 成功的软件首先是产品维度的成功
* AI时代软件生态会更加繁荣。
  * AI时代会出现更多复杂的软件应用
* AI时代会有更多的开发者
  * AI时代会有更多的初级开发者(包括不会写代码的开发者)
  * AI时代会有更多的高级开发者

## 职业能力
* 复杂是软件工程师的避风港
  * AI时代，稀缺性依然是个人价值的核心
  * 搞定问题是关键，结果是最重要的，AI只是过程。
* 软件是生命周期是对抗熵增的过程，
  * 长生命周期的软件，依赖软件质量和对质量的持续维护。
  * 长生命周期的软件，Code Review必不可少。
  * Code Review需要高级的代码能力。
* 软件工程师能力提高方向
  * 提高产品能力(业务理解、产品设计、...)
  * 深挖技术能力(并发、网络、存储、...)
  * 提高技术宽度(测试、运维、前后端、...)

## 读书 & 写作
* AI时代读书更为重要
  * 读书是体系化思考的必要手段。
  * 读书是批判式思维的基础。
* AI时代写作更为重要
  * 提问是写作的开始，也是AI时代最重要的能力
  * 写作是构建增量知识的基础。
  * 体系化创作(如写书)越来越重要。
